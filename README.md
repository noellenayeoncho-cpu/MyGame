# Jumping Orpheus
This game is about Orpheus and and adventure to getting back to safety after waking up on top of a skyscraper. The backstory shows it.
I made my game by using Godot and although its a platformer game, it has a cut scene for the backstory. All art was drawn by me on Procreate.
